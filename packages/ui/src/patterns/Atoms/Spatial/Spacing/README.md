# Spacing (SpacingScale)

**Layer:** Atom (Spatial)

**`SpacingScale`** renders the spacing scale reference for documentation. It is not a general-purpose layout wrapper.

## Import

```tsx
import { SpacingScale } from "@repo/ui/atoms";
```

## Usage

Use on style-guide / docs pages to show token steps. Spacing **tokens** for real layouts are consumed via SCSS `@use` of `spacing-variables` and related modules — see `readboot-branding.mdc`.
