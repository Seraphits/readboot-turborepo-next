# Container

**Layer:** Atom (Environmental)

Viewport-width shell with themed paper background. Use **`as`** for landmarks (`main`, `section`, `article`, …).

## Import

```tsx
import { Container } from "@repo/ui/atoms";
```

## Usage

Wrap page regions; pair with **`NavigationBar`** / footer patterns at the app level. Styles: `Container.module.scss`.

## Storybook

`Container.stories.tsx` — `as` variants (section, main, article).
