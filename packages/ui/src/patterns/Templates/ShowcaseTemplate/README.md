# ShowcaseTemplate

**Layer:** Template

Two-slot shell: **`headerSlot`** + **`mainSlot`**. Typical use: **`ReadBootBand`** / boxed hero in the header, **`Showcase`** or **`BlogShowcase`** in main.

## Import

```tsx
import { ShowcaseTemplate } from "@repo/ui/templates";
```

## Usage

Pass React nodes for each slot; no data fetching inside the template.
