# Alert

**Layer:** Molecule

Inline status / feedback message (variants for tone). Use for dismissible or static callouts below the masthead or inside forms.

## Import

```tsx
import { Alert } from "@repo/ui/molecules";
```

## Usage

Pass content as children; style via module + tokens. Prefer **`Typography`** inside for consistent type when appropriate.
