# ThemeToggle

**Layer:** Molecule

Toggles **`data-theme`** on `html` (light/dark) with localStorage persistence; used inside **`NavigationBar`**.

## Import

```tsx
import { ThemeToggle } from "@repo/ui/molecules";
```

## Usage

Mount once in a client-capable region. Docs tab in Storybook notes debugging `data-theme` / `localStorage` key **`theme`**.
