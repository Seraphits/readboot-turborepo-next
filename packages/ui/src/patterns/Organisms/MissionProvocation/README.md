# MissionProvocation

**Layer:** Organism

Mission block: two-column **newspaper** body with optional **accent** span on **`accentWord`** inside **`title`**.

## Import

```tsx
import { MissionProvocation } from "@repo/ui/organisms";
```

## Usage

Pass **`title`**, **`accentWord`**, **`paragraphs`**. If **`title`** does not contain **`accentWord`**, the title renders without accent styling.
