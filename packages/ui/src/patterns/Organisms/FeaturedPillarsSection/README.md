# FeaturedPillarsSection

**Layer:** Organism

Three-up **featured** cards with shared pillar placeholder art and **`next/link`** CTAs. **`PillarItem`** shape is defined in **`patterns/homeContentTypes/`** (not template-only).

## Import

```tsx
import { FeaturedPillarsSection } from '@repo/ui/organisms';
import type { PillarItem } from '@repo/ui/organisms';
```

## Usage

Pass **`pillars={...}`** — typically from **`homePageDefaults`** / **`docsHomeDefaults`** or app props.
