# VisionRoadmapSection

**Layer:** Organism

Vision + horizontal **timeline** of labels (`generations`).

## Import

```tsx
import { VisionRoadmapSection } from '@repo/ui/organisms';
```

## Usage

Pass **`title`**, **`body`**, **`generations`** (array of strings). Duplicate labels are supported; list items use stable keys internally.
